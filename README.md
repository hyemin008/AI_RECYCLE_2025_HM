# AI_RECYCLE_2025_HM
AI_RECYCLE_2025
제작기간(制作期間) : 2025.10 ~ 2025.11

이름(名) : AI_RECYCLE

제작(制作) : SHM(本人)

사용 툴(ツール) : HTML, teachablemachine, tensorflow

제작 목적(制作目的) : 동네마다 리사이클 기준이 다르기에 안내 어플의 필요성을 느껴서 제작하게 됨. 
웹을 접속해 사용자의 위치를 제공받고 ai가 사진을 인식해 어떻게 리사이클 해야하는지 안내함.
地域ごとにリサイクル基準が異なるため、案内アプリの必要性を感じて制作した。 
ウェブにアクセスしてユーザーの位置情報を取得し、AIが写真を認識してどのようにリサイクルすべきかを案内する。

충청북도 공공데이터 콘테스트 아이디어부문 장려상 수상
公共データコンテストで奨励賞を受賞
