제작기간 制作期間 : 2025.10 ~ 2025.11
이름 名前 : AI_RECYCLE
제작 制作 : チームリーダー SHM(本人) 他3名
사용 툴 : ツール : HTML / CSS / JavaScript / Teachable Machine / TensorFlow.js

제작 목적 制作目的 :

지역마다 재활용 기준이 달라 안내 서비스의 필요성을 느껴 제작.
웹에 접속해 사용자의 위치 정보를 수집하고,
AI가 사진을 인식해 재활용 방법을 안내하는 웹 서비스.
네이티브 앱이 아니라 웹을 채택한 이유는,
설치가 필요 없고 사용자가 바로 사용할 수 있다고 판단했기 때문에.
TensorFlow.js를 사용해 브라우저 상에서 AI 추론이 완결되는 설계를 채택.

地域ごとにリサイクル基準が異なるため、案内サービスの必要性を感じて制作。
ウェブにアクセスしてユーザーの位置情報を取得し、
AIが写真を認識してリサイクル方法を案内するWebサービス。
ネイティブアプリではなくWebを採用した理由は、
インストール不要でユーザーがすぐ使えると判断したため。
TensorFlow.jsを用いてブラウザ上でAI推論が完結する設計を採用。

수상 : 충청북도 공공데이터활용 아이디어 부문 장려상
